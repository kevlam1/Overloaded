The 2026-10-29 version of this list had 99 lines and most of them were finished or replaced. Everything that is done is in `log.md` (the entry numbers are in `CLAUDE.md`), so this list is only what is still open, plus a short section at the end that says what was dropped or parked and why. ## Decided (unchanged)
- Hosting: Vercel, builds `main`, live at https://overloaded-spell.vercel.app. Live play: Firebase Realtime Database with anonymous sign-in and Security Rules, no server (`docs/live-play.md`; the spike passed 2026-10-28).
- No accounts: a name per lobby, decks kept in the browser as text. Casual play only: no rules engine, players move their own cards.
- Formats: Commander and Standard (decided 2026-10-30). The host picks the seats; a match needs two players, all ready.
- Card data: our own list built from Scryfall's bulk files during Vercel's build (`docs/scryfall.md`), no Scryfall request while playing.
- At the start of every session, check the "Unknowns to check when their trigger happens" table in `CLAUDE.md`.
