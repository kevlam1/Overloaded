# frontend

Everything that runs in the browser.

- `pages/lobby/`: find or create a table.
- `pages/deck-builder/`: search cards, build and save decks.
- `pages/table/`: the shared play area.
- `assets/`: images, fonts and icons used by more than one page. Check a licence before adding anything that is not mine.
- `src/`: browser code shared by the pages (the connection to the backend, rendering helpers, the design system).

Empty on purpose. The framework (or none), build tool and page routing are not chosen yet, see `../CLAUDE.md` "Open questions".
